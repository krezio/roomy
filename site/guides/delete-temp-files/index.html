How to delete temporary files on Windows (and what's safe to remove)

Updated November 2026 · 4 min read

Short answer

Press Win + R, type %temp%, select everything and delete it. Skip anything that says it's in use. It's safe: apps recreate what they need.

Apps create temporary files while they work: installers unpack into them, browsers stash downloads, and updaters leave copies behind. Most apps never clean up after themselves, so the Temp folder slowly grows to gigabytes.

Is it safe to delete temp files?

Yes. Temp files are, by definition, things apps don't need to keep. The only files you can't delete are ones currently in use, and Windows will simply refuse to delete those. Nothing breaks.

Method 1: the Temp folder (fastest)

  1. Press Win + R, type %temp% and press Enter.
  2. Press Ctrl + A to select everything, then Shift + Delete to delete permanently.
  3. When Windows says a file is in use, tick Do this for all current items and click Skip.

Closing your other apps first lets you delete more.

Method 2: Windows' own cleanup

Open Settings → System → Storage → Temporary files, tick Temporary files and click Remove files. This also lets you clear other safe categories like Windows Update leftovers in the same pass.

Method 3: the system Temp folder

Windows has a second Temp folder for system processes at C:\Windows\Temp. You need admin rights to open it. It's safe to empty the same way, skipping files in use.

What not to confuse with temp files

  • Prefetch (C:\Windows\Prefetch): small, and Windows uses it to start apps faster. Leave it.
  • AppData folders in general: only caches and Temp are safe; other folders hold your app settings.
