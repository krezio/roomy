C: drive full on Windows 11 or 10? 8 safe ways to free up space

Updated November 2026 · 7 min read

Short answer

Start with the Recycle Bin, Windows' own Temporary files cleanup, and your Downloads folder. Then uninstall games and apps you don't use. Never delete things from C:\Windows, WinSxS or Program Files by hand.

When the C: drive bar in File Explorer turns red, Windows starts misbehaving: updates fail, apps crash, and games refuse to install. The good news is that most PCs have 10–40 GB of safe-to-delete junk lying around. Here's how to find it, roughly in order of how much space each step usually frees.

1. Empty the Recycle Bin

Deleted files still take up space until the bin is emptied. Right-click the Recycle Bin on your desktop and choose Empty Recycle Bin. Obvious, but it's often several gigabytes.

2. Use Windows' "Temporary files" cleanup

This is the single biggest win on most PCs, because it includes Windows Update leftovers.

  1. Open Settings → System → Storage.
  2. Click Temporary files and wait for it to scan.
  3. Tick Windows Update Cleanup, Delivery Optimization Files, Temporary files, DirectX Shader Cache and Thumbnails.
  4. Leave Downloads unticked unless you've checked what's in there, then click Remove files.

On Windows 10 the old Disk Cleanup tool does the same job: search for it, then click Clean up system files to see the Windows Update options. See also: is it safe to delete Windows Update files?

3. Clean out your Downloads folder

Downloads is where installers, ZIPs and videos go to be forgotten. Open it, switch to Details view and sort by Size. Setup files like something-setup.exe or .msi files are safe to delete once the app is installed.

4. Uninstall games and apps you don't use

Go to Settings → Apps → Installed apps and sort by Size. Games are usually the biggest items on any PC; a single modern game can be 70–150 GB. Uninstall through Steam, Epic or the Xbox app so you can reinstall later with one click.

5. Clear browser and app caches

Chrome, Edge, Discord, Spotify, VS Code and Steam all keep caches that grow over time. Clearing a cache is safe: the app just re-downloads what it needs. In Chrome or Edge, press Ctrl + Shift + Delete, choose Cached images and files, and leave cookies unticked so you stay logged in.

6. Clear the GPU shader cache

NVIDIA and AMD drivers keep pre-built game shaders that can quietly grow to several gigabytes. It's safe to clear; the only side effect is a bit of stutter the first time you launch each game afterwards. How to clear the shader cache.

7. Remove the old Windows backup

After a big Windows update, your previous version is kept in a Windows.old folder that can be 15–30 GB. If your PC has been working fine, you can remove it. How to delete Windows.old safely.

8. Find out what's actually using the space

If you've done all of the above and the drive is still full, something specific is eating it: a game, a video folder, a virtual machine, Docker, or a runaway log file. How to see what's taking up space.

What you should never delete by hand

  • C:\Windows, especially WinSxS and System32. Use the cleanup tools above instead.
  • pagefile.sys and hiberfil.sys. Windows manages these.
  • Anything inside Program Files. Uninstall apps properly instead.
  • Folders in AppData you don't recognise. Caches are fine; app data and settings are not.

Tip: Try to keep at least 10–15% of your drive free. Windows needs room for updates and virtual memory, and SSDs slow down when they're nearly full.
